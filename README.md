SOLMAR HEAT: a complete 3D open-world crime game in Solmar City. Explore a sunset coastal city on foot and by car, steal cars, outrun the police and their helicopter, and play through a 5-mission story as Dante Reyes takes on Aurelio Voss — with traffic, pedestrians, combat, crew call-ins, a HUD with minimap, and save/load. Built with three.js; runs offline in a desktop browser, no build step.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
