SOLMAR HEAT: a complete 3D open-world crime game in Solmar City. Explore a sunset coastal city on foot and by car, steal cars, outrun the police and their helicopter, and play through a 5-mission story as Dante Reyes takes on Aurelio Voss — with traffic, pedestrians, combat, crew call-ins, a HUD with minimap, and save/load. Built with three.js; runs offline in a desktop browser, no build step.

## Controls

| Key | Action |
| --- | --- |
| W A S D / arrow keys | Move on foot; drive (W accelerate, S brake/reverse, A/D steer) |
| Shift | Sprint on foot |
| Space | Handbrake while driving |
| Mouse | Look around (click the game to capture the mouse) |
| Left click | Shoot (hold for automatic weapons) |
| R | Reload |
| E | Enter / exit car (steal a nearby car) |
| 1 / 2 / 3 | Fists / P-9 Pistol / VK-9 SMG |
| Z | Crew: Getaway — Ivy sends a car |
| X | Crew: Quick Fix — Tomas repairs your car |
| C | Crew: Eyes Out — Nia marks police on the minimap |
| H | Horn (in a car) |
| P or Esc | Pause |
| M | Mute sound |

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
